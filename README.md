# Student Management System (Java + JDBC + MySQL)

## Project Description
This project is a console-based Student Management System developed using Core Java and MySQL database with JDBC connectivity.  
It helps to store and manage student records digitally instead of maintaining them manually.

## Features
- Add new student details
- View all student records
- Update student information
- Delete student records
- Menu-driven console application

## Technologies Used
- Core Java
- Object-Oriented Programming (OOP)
- JDBC (Java Database Connectivity)
- MySQL Database
- SQL (CRUD operations)

## Project Structure
- Student.java → Model class (encapsulation with getters and setters)
- DBConnection.java → Establishes connection to MySQL database
- StudentDAO.java → Handles database operations using PreparedStatement
- StudentApp.java → Main class with menu-driven interface
